# Jaanavule Nerajaanavule

## Celebrity Guessing Game

Welcome to the **Celebrity Guessing Game**! 🎉  

Reveal the tiles and guess who the celebrity is behind them. Test your knowledge of famous faces and have fun while playing!

---

## Installation

1. Clone the repo
```bash
https://github.com/vishnuvardhangude/jaanavule-nerajaanavule.git
```
2. Install Dependencies
```bash
npm install
```
3. Run the Application
```bash
npm run dev
```
